## Code of Conduct

All contributors must follow our [Code of Conduct](./CODE_OF_CONDUCT.md). Report unacceptable behaviour to `conduct@opensourcemaintainertoolkit.dev`.

## Ways to Contribute

- Fix typos or broken links (Trivial — 100 points)
- Expand a guide, add examples, or create a checklist (Medium — 150 points)
- Write a comprehensive tutorial, translate documentation, or build a full resource (High — 200 points)
- Review pull requests and help other contributors
- Suggest improvements via a [feature request](./.github/ISSUE_TEMPLATE/feature_request.md)

## Claiming an Issue

1. Browse the [open issues](https://github.com/your-org/open-source-maintainer-toolkit/issues).
2. Look for labels: `good first issue`, `documentation`, `help wanted`.
3. Comment on the issue with **`I’d like to work on this`** and mention your relevant experience.
4. Wait for a maintainer to assign you. **Do not start work before being assigned.**
5. If the issue is part of a Drips Wave Program, also apply through the [Drips Wave app](https://www.drips.network/wave).

> **Tip:** Start with a `good first issue` (Trivial complexity) to understand the workflow before moving to Medium or High tasks.
