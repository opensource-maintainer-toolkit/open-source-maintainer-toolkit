# Open Source Maintainer Toolkit

A curated collection of templates, checklists, guides, and resources for **new open-source maintainers**, with a focus on **Drips Wave participation**.

Whether you are launching your first project or preparing to onboard your repositories to a Drips Wave Program, this toolkit gives you copy-paste-ready templates and step-by-step guidance so you can spend less time on setup and more time building.

---

## What’s Inside

| Directory | Purpose |
|---|---|
| [`docs/`](./docs) | In-depth guides: getting started, maintainer workflows, contributor onboarding, Drips Wave points, FAQ |
| [`templates/`](./templates) | Ready-to-use checklists and templates for issues and pull requests |
| [`.github/`](./.github) | Issue templates, pull request template, and community health files |

---

## How to Use This Toolkit

1. **Fork or clone** this repository.
2. Browse the [`docs/`](./docs) guides for the topic you need.
3. Copy the relevant template from [`templates/`](./templates) or [`.github/`](./.github) into your own project.
4. Customize placeholders (organisation name, repository name, labels) to match your project.
5. Onboard your repository to a Drips Wave Program (see [`docs/drips-wave-points.md`](./docs/drips-wave-points.md)).
6. Start scoping **good first issues** and welcome contributors.
