## Before You Start

### Create a GitHub Account

If you don’t have one, [sign up](https://github.com/join). Use a professional username — maintainers see it on your PRs.

### Set Up Git

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
