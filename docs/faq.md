# Frequently Asked Questions

---

## General

### What is the Open Source Maintainer Toolkit?

A curated collection of templates, checklists, and guides for new open-source maintainers, with a focus on Drips Wave participation. It is a **documentation-only** repository — no code to build.

### Who is this for?

- First-time maintainers launching a project
- Experienced maintainers preparing to onboard to Drips Wave
- Contributors who want to understand how maintainership works

### Is this repository open source?

Yes. It is released under the [MIT License](../LICENSE).

## Contributing

### How do I claim an issue?

Comment on the issue with your plan and wait for assignment. If the issue is part of a Drips Wave Program, also apply through the Drips Wave app. See [CONTRIBUTING.md](../CONTRIBUTING.md).

### Do I need to be an experienced developer?

No. Many issues are documentation-only and labelled `good first issue`. If you can write clear Markdown, you can contribute.

### Can I contribute without code?

Yes. Documentation, translation, design, and triage are all valuable contributions. If the work is scoped as a Drips Wave issue, you earn points for it.

### How long does a review take?

Maintainers aim to respond to new PRs within **48 hours**. If you haven’t heard back in three days, leave a polite comment on the PR.

### What if my PR is rejected?

A rejection is not a judgment of you. Maintainers may close a PR if it duplicates existing work, is out of scope, or does not meet the acceptance criteria. Ask for clarification and consider opening a new PR addressing the feedback.

## Drips Wave

### What is Drips Wave?

A recurring contribution sprint where maintainers nominate issues and contributors solve them for points. At the end of each Wave, a reward pool is distributed based on points earned[reference:25].

### Is it free?

Yes. Participation is free for both maintainers and contributors. Contributors need KYC verification and a wallet address to withdraw rewards[reference:26].

### How many points is an issue worth?

| Complexity | Points |
|---|---|
| Trivial | 100 |
| Medium | 150 |
| High | 200 |

See [`drips-wave-points.md`](./drips-wave-points.md) for full details.

### How do I earn 400 points?

Complete two High (200-point) issues, or one High + one Medium + one Trivial, or four Trivial issues. You can also earn bonus points through a maintainer Compliment.

### When do I get paid?

After the Wave ends and the 7-day Compliment Window closes, rewards are distributed. You’ll receive an email when they are available to withdraw[reference:27].

### My PR was merged but I didn’t get points. Why?

Points are awarded when the **issue is closed as completed**. If your PR was merged but the issue remains open, remind the maintainer to close it. Also ensure your PR description uses `Closes #<issue-number>` so GitHub closes the issue automatically[reference:28].

### Can I work on multiple issues in one Wave?

Yes. There is no limit, but do not over-commit. It is better to complete one issue well than to half-finish three.

## Maintainership

### How do I onboard my repository to Drips Wave?

You need a GitHub **organisation**, at least 5–10 scoped issues, and approval from the Wave Program organiser. See [`drips-wave-points.md`](./drips-wave-points.md) and the [Drips documentation](https://docs.drips.network/wave/maintainers/participating-in-a-wave/).

### What if my repository application is rejected?

You can appeal from the Maintainers → Orgs and Repos dashboard. Appeals require substantive change since rejection. First appeal: 2 weeks after rejection. Cooldown after declined appeal: 1 month. Maximum three appeals per repository[reference:29].

### How much time does Drips Wave take as a maintainer?

- **Pre-Wave:** 1–2 hours scoping issues
- **During Wave (1 week):** Daily dashboard checks (15–30 minutes per day)
- **Post-Wave:** Review and merge PRs, issue Compliments

### Can I set the complexity of an issue?

Yes. The maintainer has final say on complexity. When adding an issue via the Drips app, you choose Trivial, Medium, or High. Issues added via GitHub label default to Trivial (100 points) — edit them in the app to raise the value[reference:30].

## Troubleshooting

### A link in the toolkit is broken. What do I do?

Open a [bug report](../.github/ISSUE_TEMPLATE/bug_report.md) with the broken link and the file it appears in.

### I disagree with a maintainer’s decision. What can I do?

Communicate on the GitHub issue or PR first. If the disagreement persists on a Drips Wave matter, contact [Drips Wave Support](https://www.drips.network/wave/support)[reference:31].

### Can I suggest a new template or guide?

Yes. Open a [feature request](../.github/ISSUE_TEMPLATE/feature_request.md).
